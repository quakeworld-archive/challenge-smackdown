Group A
Firing Squad VS Daltons


Round 1 - mirco

Firing Squad 168
Daltons 73
DM3 - The Abandoned Base (Firing Squad's choice)


Demos

POV: forsaken

POV: crit

POV: rat

Report
In this game between the Dutch clan Firing Squad and the Finnish Daltons, dm3 should be the one and only map. The server was get2net (denmark) and had been chosen as the server in advance. Pings were indeed very equal, both teams getting avg pings around 54-58ms. Daltons' Some had connection problems before the game but he was able to fix it so the game would start.
The first map was only interesting for about the first 3 minutes, then FS totally controlled the map and the Daltons couldn't find a way back into it. Although Daltons managed to get most Pents even when FS was controlling, they didn't use them too well and never got any control.



Round 2 - mirco

Firing Squad 152
Daltons 109
DM3 - The Abandoned Base (Firing Squad's choice)


Demos

POV: forsaken

POV: crit

Report
The second map was a lot more interesting. It started closely but FS could gain a little control and frags. The Daltons hit back hard though, and soon they were in control of Red Armor and running Quad continuesly. That didn't change for some time and Daltons led by about 25 frags already, when the specs already hoped for the third map. It didn't look too good for FS. But everything would change when 3 Daltons covered the Pent and F0rs4k3n jumped down the window, killed 2 of them and got the Pent. That brought FS back into the game, which they would finally decide for them by quite a large margin again. Although the scores might look as if it was a boring and one sided game, it surely wasn't.
