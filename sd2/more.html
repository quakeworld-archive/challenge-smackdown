Challenge Smackdown Headquarters


More...

Just in case you missed it, we wanted to make sure that you know there are some "extra" goodies on this CD:

  • QuakeWorld - essential QW files.
  • Qizmo - essential Qizmo files required to setup Qizmo.
  • Demos Guide - guide to using QW and Qizmo to play SD2 demos.
  • Map Guides - guides to the maps played in SD2.
  • Interviews - various interviews.
  • Stats - statistical information on the games played in SD2.
  • Online Links - useful Web Sites on the Internet.
  • FFA Allstar Demos - some unique FFA demos featuring star players.
  • Commented Demos - some demos with voice commentary (instructions included).
  • QW Skins - some QW "skins" which make it easier to tell teams apart.
  • CD Cover - the CD cover graphic.
