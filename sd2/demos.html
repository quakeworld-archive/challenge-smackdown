Challenge Smackdown 2 CD Demos

The demos on the CD are stored in the .QWZ format. It is important to realise that this is different from the file type normally used by QuakeWorld (.QWD) and therefore the demos can not be viewed immediately.

.QWZ has been chosen since it is much more compact then .QWD (about 10 times!), enabling us to fit many more demos on the CD.

Here we'll explain how to get the demos to play in QuakeWorld. All examples will be given for PCs running Windows. If you are using a different operating systems, you will have to find out how folders or directories behave there. If you have QuakeWorld installed, skip the first part.

Installing QuakeWorld
QuakeWorld is an improvement to Quake (the original also known as Quake 1 or NetQuake), mainly for internet play. QuakeWorld is necessary to play demos on this CD.
Assuming you installed Quake from the original CD first, you can find the latest QuakeWorld release at id softwares server, or version 2.30 for Windows on this CD. Just follow the instructions of the installer.

Installing Qizmo Qizmo is an extension of QuakeWorld which provides usefull features, for example for teamplay. It has to be installed seperately and you will need it to view the demos on this CD.
The latest version of Qizmo can be found on the Qizmo homepage, but version 2.91 is included on this CD. Extract the .zip file to your Quake directory, usually C:\QUAKE\.
To make the rest of the procedure easier, its best to also intstall Qizmo to the C:\QUAKE\QW\ folder.

Getting demos from the CD
There are two ways to access the demos on this CD:

  • with your browser through the reports: right click on the demo link and save the file to the C:\QUAKE\QW\ folder. The reports can be found at the division pages linked on the left.
  • by directly accessing the demo section of the CD (the DEMOS\ folder) with Windows Explorer or a similar utility. The demos are sorted in folders per division and group, and are named as follows: tag1_tag2_X_map_pov_sd2_group.qwz, which means:
    • tag1: the short version of the first teams name
    • tag2: the short version of the second teams name
    • X: the round in the match which the demo is from
    • map: the map played in the demo
    • pov: the player who recorded this demo
    • sd2: Challenge Smackdown 2
    • group: the group in which the game occured
    Copy the demos you like to watch to C:\QUAKE\QW\.

Converting demos
Suppose you have saved the demo to the C:\QUAKE\QW\ folder as 'sd2demo.qwz. There are 2 methods of viewing the demo. The first one is decompressing it:

  • decompress the demo: at a command prompt type 'C:\QUAKE\QW\qizmo -D C:\QUAKE\QW\sd2demo.qwz' (capital D, all in one line!)
  • start QuakeWorld by clicking on its icon in C:\QUAKE\
  • play the demo by typing playdemo sd2demo in the console (if you use the original long demos names, you can actually copy and paste the it in the console using CTRL+V).
Alternatively, you can use Qizmo to view the demo:
  • start Qizmo in the C:\QUAKE\ folder by clicking the icon
  • start QuakeWorld by clicking on its icon in C:\QUAKE\
  • in the console, type '/connect localhost'
  • still in the console, type '.menu bindstd'
  • you should now be able to use the arrow keys to move around Qizmos menu. Find the demo list and select the demo you want to see.
In some cases, you may want to combine these two methods: first decomress the demo, than view it through Qizmo. This has the advantage that you will be able to rewind the demo if you would like to take another look at a great frag or a particular move.

More info
Qizmo has an excellent readme, which you should check out if you want to learn more about its features for online playing.
