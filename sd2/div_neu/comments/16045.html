Status - Apollyon - 25/01/01

"I am in a fucking bad mood and i need to laugh at some poor creatures!"
A few of the qualifier matches have already been played, some have even been reported to me. Unfortunately only one, maybe two of these matches went smooth. The rest was characterized by cheat attempting (changed models, palettes etc.), moaning and utter lameness in general. Nice work boys, you have proven that you would be worthy parts of the Counterstrike community!
To make it clear: request an admin in #smackdown as soon as problems occur. I feel not responsible for sorting out any issues that come up without smackdown officials being present. I also don't want to shedule your games. This is up to you (at least in the qualifier round) and in my opinion you should be old enough to be able to do that in a civilized manner. If your team is only able to play once a week on sunday morning you really should not have signed up...

Now to part of this update for the mature people who are actually interested in playing QW instead of annoying officials:
I will post the results of the qualifier games as soon as they are all done which will hopefully happen during the next few days.
There will be a public group drawing for the north european division tomorrow at 22:00 CET on #smackdown.
The group games will not start before the new site is finished. The design is finished already. I have seen it today and it looks very nice and clean. Way better than what we currently have/used last season (and its better than villains :p ). Tanks to Cyklops for creating it. Unfortunately we can not apply it yet because we lack a backoffice and scripts. This was to be done by Droogie but he is gone/dead/whatever. So thanks to him, too. Jjonez has found an alternative we can use but it needs a few days work until we can use it. I don't want to start the season doing things 'manually' like some other divisions because we actually did that last season and it sucked. So now i am aiming for the 1st of february to start the group games. If the new design and everything is applied earlier we will start earlier as well.
Note that the rule concerning adding players will kick in from today. And in case you have not done it yet (and thats obviously the case with a lot of people), read the rules.
The quote on the top is from a site of a good friend of mine, the QW community definately needs somethign similar...
